# Work queue

This repository is **public**, and its work queue is not.

Open items, half-finished thoughts and "this is broken and here is why" notes are the most candid
writing a project produces. They are useful to the people building this and misleading to everyone
else, who has no way to tell an idea from a commitment. So they are kept in the maintainers' own
private store, and `.gitignore` keeps `docs/todo/*` out of this repository - this README is the
only file here.

What IS published, and deliberately so:

- `docs/research/` - the measurements, including the ones that did not go our way. The 2026-09-19
  burn-down report records tested hardware, NumPy versions, retained limitations and separately
  qualified numbers; it does not promise universal speedups.
- `CHANGELOG.md` - what actually shipped.

If you are looking for what is wrong with this project today, the issue tracker is the right place
to ask, and an honest answer is the intent.

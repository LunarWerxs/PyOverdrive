# Batch-3 lead shortlist (mined 2026-08-24)

Sweep: 299 fresh numpy/numpy candidates (10 search angles, deduped against
the 22 ingested leads) -> 97 kept by title triage -> 72
scored by thread-reading agents (0-10 shippability). Chosen for ingestion:
32187, 32161, 24821, 9909, 8480, 10468, 28714. Full ranking below;
unchosen rows stay here as the bench for batch 4.

Batch-4 draw (2026-08-24): 24565 (OPP-000029, SHIPPED matmul_split_complex),
22158 (OPP-000030, SHIPPED eigvalsh_2x2_closed), 12389 (OPP-000031,
not_reproduced - alias-only win), 10848 (OPP-000032, SHIPPED
roll_concat_1d), 7487 (OPP-000033, not_reproduced - NaT guard inverts the
modern margin), 9182 (OPP-000034, built then UNSHIPPED: the Intel win is
a measured Zen 4 regression; needs per-machine calibration to return).

are 28711 (transpose-copy, largely covered by relayout_blocked), 25872

## Evidence rules

Ratios are **stock median seconds / dispatched median seconds**, rounded to
four decimals. A value below 1 is a slower public call. A stock refusal is
policy evidence and never a candidate speedup. Correctness uses the operation's
recorded comparison mode; numeric matmul agreement is not described as bitwise.

Each cell runs in a fresh child with raw samples, shapes/dtypes, dispatch and
correctness records. Strict evidence records actual execution without runtime
fallback; vectorize also records its direct ufunc. Inputs for safe-output
comparisons are reset outside timing. Guard bypasses are benchmark-local,
restricted to proven-safe aliases, and never alter shipped runtime behavior.
Their end-to-end timing difference does not isolate the guard's instruction
cost.

Known foreign CPU load must be at most **20%** at both bracketing samples.
The general sweep records a batch envelope; the supplementary runner records
each child's envelope and may retain qualified children after a contended
parent finish. Neither proves continuous quiet. Intel hybrid-core probes
reject slow-core draws. The new dispersion gate also rejects a timing series
when **median absolute deviation / median exceeds 20%**, including apparent
wins. An older artifact's successful exit code does not override that check.

Source-content manifests, optional Git revisions, benchmark-script hashes,
requested cell lists and selection hashes are retained in JSON. Artifacts
span source snapshots; their counts must not be combined into a fictitious
single passing run. Memory checks precede allocation. Quiet refusals can be
retried by exact cell list without repeating accepted children; unresolved
cells keep the run nonzero. Failed children, malformed evidence and incorrect
results remain failures.
